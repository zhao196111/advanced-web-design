JavaScript 对象

对象是一组「键值对」：属性存数据，方法存函数。这一页练五件事 —— 属性的读写增删、判断属性是否存在、for...in 遍历、 方法里 this 指向谁，以及引用赋值之后两个变量为什么会一起变。 每段代码下面都是真实运行结果。

1. 对象的属性与方法

用花括号声明对象，键: 值 之间用逗号分隔。值是函数的，就叫这个对象的方法。

// 一个学生对象：前两个是属性，hobbies 是数组，sayHi 是方法
var student = {
    name: '赵俊清',
    hobbies: ['打游戏', '看电影', '看书'],
    sayHi: function () {
        // this 指向调用这个方法的对象，这里就是 student
        return '大家好，我是' + this.name;
    }
};

console.log(student.name);        // 点语法
console.log(student['name']);    // 方括号语法，键要用引号包起来
console.log(student.sayHi());     // 调用方法，记得写括号

            


            
            

                
2. 增、删、改、查

                
对象是「动态」的：随时可以加属性、改属性、删属性，不需要提前声明字段。


                
var user = { name: '赵俊清' };

user.age = 20;                 // 新增：这个键原来不存在，直接赋值就是加
user.name = '赵俊清（改过）'; // 修改：键已存在，赋值就是改
delete user.age;               // 删除：delete 删掉键和值

// 判断属性在不在，两种写法结果不一定一样
'name' in user;                // true
'age' in user;                 // false，刚被 delete 掉了
user.hasOwnProperty('name');     // true，只查对象自己的属性

                


                

                    in 和 hasOwnProperty 的区别：in 会顺着原型链往上找，
                    hasOwnProperty 只看对象自己身上有没有。所以用来「过滤」时，用后者更准。
                

            


            
            

                
3. for...in 遍历

                
for...in 把对象的键一个个取出来，遍历顺序是先整数键、再按书写顺序。


                
var book = { title: '高级网页设计', price: 45 };

for (var key in book) {
    console.log(key, book[key]);   // 键 + 值（值要用 book[key] 取）
}

                


                
有继承属性的时候要注意

                
// Object.create(base)：base 成为新对象的原型，新对象会“继承”到 base 的属性
var base  = { type: '教材' };
var book2 = Object.create(base);
book2.title = '高级网页设计';
book2.price = 45;

// for...in 会把继承来的 type 也遍历出来
for (var k in book2) { console.log(k); }

// 加上 hasOwnProperty 过滤，就只剩自己的属性
for (var k in book2) {
    if (book2.hasOwnProperty(k)) { console.log(k); }
}

                

            


            
            

                
4. 引用赋值：两个变量指向同一个对象

                

                    基本类型（数字、字符串、布尔）赋值时复制的是「值」；对象赋值时复制的是「地址」。
                    所以两个变量会指向同一个对象，改任何一个，另一个看到的结果也跟着变。
                


                
// ① 对象：赋的是地址
var a = { num: 1 };
var b = a;          // b 和 a 指向同一个对象
b.num = 99;

// ② 基本类型：赋的是值
var x = 1;
var y = x;          // 把 1 复制一份给 y，之后互不相干
y = 99;

console.log(a === b);   // 同一个对象的两个名字
console.log({} === {}); // 内容一样，但它是两个不同的对象

                

            


            
            

                
5. 方法里的 this 指向谁

                

                    方法里的 this 不在写的时候决定，而在调用的时候决定：
                    谁调用这个方法，this 就是谁。把同一个方法挂到另一个对象上，结果就变了。
                


                
var someone = { name: '小明', sayHi: student.sayHi };

someone.sayHi();   // this 是 someone → 大家好，我是小明
student.sayHi();   // this 是 student → 大家好，我是赵俊清

                

            


            
            

                
6. 不想共享怎么办：拷贝一份

                
要避免「改一个动两个」，就把对象复制一份。但直接复制是浅拷贝，只断开最外面一层。


                
// Object.assign(目标, 来源)：把来源的属性复制到目标，得到新对象
var copy = Object.assign({}, student);
copy.name = '副本';              // 顶层属性断开了，student.name 不变
copy.hobbies.push('游泳');       // 但 hobbies 是数组，还是同一个！

// 深拷贝：转成字符串再转回来，嵌套的那一层也复制了
var deep = JSON.parse(JSON.stringify(student));
deep.hobbies.push('跑步');       // 这次真的互不相干了

                


                

                    注意：JSON 这套深拷贝会丢掉函数（sayHi 复制不过来）
                    和 undefined，只适合纯数据的对象。
