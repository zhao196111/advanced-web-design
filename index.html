02

技术地图

SKILL MAP

这门课实际用到的技术点，以及各自落在哪一页。

A1 HTML 结构与语义 六级标题、段落、列表、表格、图片、超链接，以及 header / nav / main / aside / footer 的语义划分。 模块 01 →
A2 表单与控件 form、input 的多种 type、label 的 for 关联、select 下拉、textarea 文本域、required 校验。 模块 01 →
B1 CSS 选择器 元素、类、ID、后代、子代、兄弟、属性、伪类、伪元素，十种写法的优先级与用法。 模块 02 →
B2 盒模型与层叠 content / padding / border / margin 的尺寸计算，box-sizing 的影响，以及样式的层叠与继承。 模块 03 →
C1 Flex 弹性布局 主轴与交叉轴、justify-content、align-items、flex-wrap 换行、gap 间距、子项定宽。 模块 03 →
C2 Grid 网格布局 grid-template-columns 的 repeat 与 fr 单位，一行三列的图片卡片排版。 模块 04 →
D1 过渡与关键帧动画 transition 的四个属性、transform 的位移旋转缩放倾斜、@keyframes 定义循环动画。 模块 05 →
E1 SVG 图标系统 symbol 定义图形、use 复用引用、currentColor 跟随文字颜色，图标不再依赖图片。 模块 06 →
E2 JavaScript 对象 键值对读写、delete 与 in、for...in 遍历、this 指向、引用赋值与深浅拷贝的区别。 模块 06 →
F1 Swiper 轮播与效果 autoplay 的 delay 与 disableOnInteraction、可点击的分页器、cube / fade / coverflow / flip / cards 六种效果，以及 custom 的 creativeEffect（prev / next 的 translate 与 rotate）。 模块 08 →
F2 键盘交互 Swiper 的 keyboard 模块：enabled、onlyInViewport、pageUpDown 三个开关，用方向键控制轮播而不与页面滚动打架。 模块 08 →

这个站是我这门课的练习总入口。每上完一次课，我就把当堂写的页面丢进对应的模块里， 顺手在卡片上补一句这一页练的是什么，回头复习的时候不用再一个个点开猜。

页面全部是原生手写，没有引入任何框架或者 CDN。样式大多直接写在页面里， practice 那一套抽了公共的 theme.css 出来，方便十张练习页统一风格。

  • 结构按教学进度分模块，编号与课堂顺序一致，新增练习往后接。
  • 命名练习页用"编号-主题"命名，一眼能看出先后和内容。
  • 注释CSS 里保留了当堂写的说明，比如第 3 节的选择器优先级。
