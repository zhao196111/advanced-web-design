CLASS PRACTICE · 02 · 表单控件

表单控件练习

文本框、密码框、文件上传、文本域、下拉列表 —— 五个最常用的控件各写一遍， 重点看 type 一改，浏览器给的默认交互就完全不同。

五个基础控件

type="text" · 单行文本输入
type="password" · 输入内容显示为圆点
type="file" · 由浏览器调起本地文件选择框
textarea · 用 cols / rows 控制初始大小，右下角可以拖拽
select > option · 下拉列表

控件对照表

控件 写法 要点
文本框 <input type="text"> 用 placeholder 写提示文字
密码框 <input type="password"> 只改变显示，值本身不变
文件上传 <input type="file"> 加 multiple 可以多选
文本域 <textarea> 双标签，内容写在标签之间
下拉列表 <select><option> value 是提交给服务器的值
课堂小结：表单三件套 —— form 负责提交去哪儿， input / select / textarea 负责收数据，label 负责让文字也能点。 三者配合，键盘操作和读屏软件才都友好。
