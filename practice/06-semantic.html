第一部分：看代码找错

  1. 图片放大跑出卡片：.box li 缺少 overflow: hidden;，修改为：
    .box li{
        width: 300px;
        overflow: hidden;
        position: relative;
    }
  2. 鼠标移出没有过渡：transition 不能只写在 hover 上，应写在普通选择器里：
    .box img{
        width: 100%;
        transition: all .6s;
    }
    .box li:hover img{
        transform: scale(1.2);
    }
  3. 文字条定位错乱：文字是绝对定位，父级 li 要相对定位：
    .box li{
        position: relative;
    }

第三部分：手写原理简答

1. 父相子绝位置关系图

子元素
absolute
父元素 position: relative

父元素设置 position: relative; 后，子元素设置 position: absolute;，子元素就以父元素为参照，再用 bottom、left 等属性定位。

2. overflow:hidden 的两个作用

  • 作用 1：图片 transform 放大后，超出 li 的部分被裁掉，不会盖住旁边的卡片。
  • 作用 2：文字条高度较小时，多余内容隐藏；hover 后再展开显示更多文字。

3. transform:scale(1.2) 会不会挤压旁边卡片？

不会。transform 只是视觉变形，盒子原来的宽高和实际占位不变，所以不会把旁边卡片挤开。但父级如果没有 overflow: hidden，放大的图片会从视觉上盖到旁边。

4. transition 写在 hover 和普通选择器的区别

写在 :hover 上时，鼠标移入有动画，移出时普通状态没有 transition，会直接跳回原样。写在普通选择器上，移入和移出都能用同一个过渡效果。

5. 自己写代码遇到的 bug

我一开始把 transition 写在 hover 选择器里，鼠标移入时文字条能慢慢展开，但移出时高度马上变回去，没有动画。后来检查写法，发现 transition 应该写在默认的 p 选择器里，改完后移入移出都有平滑过渡。
