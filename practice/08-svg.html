SVG 图标

图标用 <svg> > <symbol> 定义成符号表，页面上用 <use href="#icon-xxx"> 引用；点击底部标签栏切换选中态， 由一小段 JavaScript 增删 active 类。往下滚到底，点那张悬浮胶囊试试。

四个图标

同一份符号表，被页面里多处引用。形状只写一遍，改一处全局生效。

浏览器 #icon-browser
关注 #icon-love
定位 #icon-positioning
分享 #icon-nav

这一页练了什么

  • symbol + use：图标只写一遍，多处复用；viewBox="0 0 24 24" 决定图标自身的坐标系。
  • 图标跟随文字颜色：.icon 上写 fill: none; stroke: currentColor;，文字色一变图标就跟着变，不用单独给图标配色。
  • 固定定位：标签栏 position: fixed; bottom: 20px;，滚动时停在窗口底部；它不占文档流，所以主体区要补下边距。
  • class 切换：querySelectorAll 拿到全部标签，classList.remove 清掉旧的选中态，再给当前这一项 classList.add('active')。
<svg class="icon" aria-hidden="true">
    <use href="#icon-browser"></use>
</svg>

.icon { fill: none; stroke: currentColor; }   /* 颜色跟着文字走 */
.tab-item.active { color: #fff; background: linear-gradient(135deg,#2563eb,#3b82f6); }

/* 点击时：先全部清掉，再给当前这一个加上 */
function changeTab(current) {
    var items = document.querySelectorAll('.tab-item');
    for (var i = 0; i < items.length; i++) { items[i].classList.remove('active'); }
    current.classList.add('active');
}
为什么要用 symbol 而不是四张 png？ ① 矢量图放大不糊；② 颜色可以用 CSS 改（currentColor），一套图标能出深色 / 浅色两版； ③ 只加载一次，页面里引用多少次都不会多发请求。
