CLASS PRACTICE · 04 · 页面布局

上图下文

图片在上、文字在下，用 ul > li > a > img + p 的列表结构做成图片卡片， 再用 Grid 网格排成一行三张。鼠标移上去，卡片会抬起来，图片会慢慢放大。

一行三张的图片卡片

整张卡片都是可点的链接。排版靠 display: grid + grid-template-columns: repeat(3, 1fr)， gap 只管卡片之间的空隙，不用再算 margin。

  • 人生要有弹性

  • 提升自适应能力

  • 适应国家发展

  • 适应岗位需求

  • 适应环境

  • 适应科技发展

核心 CSS

ul.list1 {
    list-style: none;
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 一行三张，改成 2 就是一行两张 */
    gap: 20px;
}

ul.list1 li  { border-radius: 14px; overflow: hidden; }      /* 裁掉放大的图片 */
ul.list1 img { width: 100%; height: 172px; object-fit: cover;
               transition: transform .6s ease; }             /* transition 写在默认态 */
ul.list1 li:hover img { transform: scale(1.12); }              /* 移入放大，不溢出 */
ul.list1 p   { padding: 12px; text-align: center; }            /* 下文：水平居中 */
两个小陷阱： ① transition 必须写在默认状态里，写在 :hover 上的话，鼠标移出会"啪"地跳回去； ② 图片放大会溢出卡片，靠父级 overflow: hidden 裁掉，否则会盖住旁边的卡片。

换成一行两张 / 一行一张

只改 grid-template-columns 一个值就够：repeat(2, 1fr) 是两张， 1fr 是一张。真正需要响应式时，用媒体查询按屏幕宽度切换（本页 860px 以下自动变两列，560px 以下变一列）。
