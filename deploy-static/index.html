02

这六步在做什么

FLOW
  • 立规矩：AGENTS.md 写死端口 8205、命名前缀 zjq_、记录文件追加规则、统一 JSON 格式。
  • 搭骨架：git init + .gitignore、frontend/ 与 backend/ 目录、npm 换国内镜像装 express / mysql2 / cors / dotenv。
  • 跑起来：start.bat 用 %~dp0 切到 backend 后 npm run dev，chcp 65001 防乱码，结尾 pause 防闪退。
  • 连数据库：database.html 把账号密码交给 /api/db-test，成功绿、失败红，控制台同步输出。
  • 全链路：/api/news 与 /api/gallery 直读 MySQL，页面顶部显示接口地址，fetch 后 console.log。
  • 接大模型：llm-app 课新增 /api/chat、/api/kb/*、/api/vision、/api/asr，Key 只在 backend/.env。
  • 留证据：zjq_prompt.md、zjq_interface.md、zjq_database.md 三个文件一律追加写入。
