每一格对应哪个知识点

  • :nth-child(2) 第 2 个孩子 → 换色、字号变大
  • :nth-child(3):hover 悬停 → 圆角 50% 变圆
  • :nth-child(4):hover 悬停 → box-shadow 阴影
  • :nth-of-type(4):hover → text-shadow 文字投影
  • :nth-of-type(5):hover → 线性渐变背景
  • :nth-of-type(6) → 径向渐变背景
  • :nth-of-type(7):hover → rotateY(180deg) 翻转
  • :nth-of-type(8):hover → translate 平移
  • :nth-of-type(9):hover → skew 倾斜
  • :nth-last-child(3):hover → scale(.55) 缩小
  • :nth-last-child(2):hover → rotate + scale 组合
  • :last-child:hover::before → 伪元素加一个 #

入场动画

打开这一页时看到的"依次落下"，是 @keyframes + animation-delay 做的：

@keyframes boxIn {
    from { transform: translateY(-60px); opacity: 0; }
    to   { transform: translateY(0);     opacity: 1; }
}

.box               { animation: boxIn .6s ease both; }   /* both：保留首尾状态 */
.box:nth-child(2)  { animation-delay: .06s; }            /* 依次延后 */
.box:nth-child(3)  { animation-delay: .12s; }
踩过的坑：原来写的是 animation: box 1s ease forwards;， 但关键帧定义的名字叫 boxIn —— 名字对不上，动画根本不跑。 动画没反应时，先检查 @keyframes 的名字和 animation 里写的是不是同一个。

:nth-child 和 :nth-of-type 有什么区别

:nth-child(n) 在所有兄弟元素里数第 n 个，如果那个位置不是同类标签就不生效； :nth-of-type(n) 只在同一种标签里数。 这一页的 12 个方块都是 div.box，两种写法结果一样，但换成"标题 + 段落混排"就会差很多。
