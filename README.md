## 技术说明

- 全部使用原生 HTML / CSS / JavaScript 手写，未引入任何框架或 CDN。
- 首页与各练习页共用一套视觉规范：米色纸底、墨黑正文、朱红强调，栅格以细线分隔。
- practice 目录下的十张练习页共用 `css/theme.css`，单个页面只负责自己的版式。
