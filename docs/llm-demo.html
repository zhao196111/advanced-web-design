01 CHAT / SERVICE

🤖AI 聊天 · 硅基流动 / 七牛 切换

前端通过下拉框切换 AI 服务商（硅基流动 / 七牛），后端从 .env 读取配置转发请求即可切换模型来源。多轮对话由前端维护完整 messages 数组实现——切换平台后历史上下文继续有效。客服人设只回答营业时间、招牌菜、配送范围三类问题，AI 回复下方标注了本次实际使用的平台与模型名。

02 RAG / KNOWLEDGE

📚知识库 · 上传文件 + 功能验证

自行上传 txt / md / csv / json / pdf / doc / docx / ppt / pptx 文档，后端自动解析、去格式、按 320 字切片（重叠 60 字） 后存入本地 JSON 主存储。提问时先对全表做关键词 + 中文二元组检索取 Top-K，拼进 system 提示词要求"仅根据资料回答"，实现检索增强生成（RAG）。预置 2 个知识库文件，一键 seed 构建。

03 VISION / MULTIMODAL

🖼️图像识别 · 上传图片 + Vision

上传本地图片转 base64 data URI，由后端携带 API Key 调用多模态视觉模型（Qwen/Qwen2.5-VL-32B-Instruct），图片以 image_url 形式放进 chat/completions 请求体，返回对物体 / 文字 / 场景的中文描述，支持自定义提问。

04 ASR / SPEECH

🎤语音识别 · 录音 + 测试功能

浏览器原生 MediaRecorder 录音，或直接上传音频文件（WAV / MP3 / M4A / AAC / OGG / WEBM / FLAC），后端内存接收后转发七牛云语音识别模型 qwen/qwen-audio-3.0-asr-flash，音频转 data URI 放进 input_audio.data 消息，开启 enable_itn=true（文本标准化），返回识别文字。页面提示在 Chrome / Edge 中允许麦克风权限。

POST /api/asr MediaRecorder input_audio.data Qwen ASR 七牛云
