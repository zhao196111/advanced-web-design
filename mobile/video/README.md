# 真机演示视频放这里

任务三、任务四按要求需要"另一台设备录制"的手机端效果视频。录制完成后把文件命名如下放进本目录，
页面上对应的视频位会自动加载，不需要改代码。

| 文件 | 对应页面 | 拍什么 |
|---|---|---|
| `task3.mp4` | mobile-zoom.html | 双指放大（看右下角倍数）→ 松手拖动 → 双击回 1× → 再双击 2× → 横屏再竖回 |
| `task4.mp4` | mobile-sensor.html | 仪表静止 9.8 → 摇一次出菜（摇动次数 +1）→ 立刻再摇（被冷却挡住）→ 点"点我抽一次" |

拍摄建议：

- 竖屏，15～30 秒，720p 以上；用另一台手机拍屏或系统录屏都可以。
- 画面里要同时看清"手指动作"和"页面变化"，手指别挡住右下角的倍数指示器 / 加速度仪表。
- 视频编码用 H.264（mp4），Safari 与安卓 WebView 都能直接播放。
- 单个文件建议控制在 10MB 以内，太大的话先压缩：`ffmpeg -i raw.mov -vcodec h264 -crf 26 -vf scale=720:-2 task3.mp4`

未放入视频时，页面会显示一个深色的占位框，写明该位置等待哪个文件，不会出现破图。
