用 flex 弹性布局排卡片：flex-wrap 负责换行，gap 负责间距， 给 li 定宽就实现一行三张。下半部分换成父相子绝，把文字条压到图片上。

结构和上面一模一样，只多两步：li 设 position: relative（父相）， p 设 position: absolute 定位到底部（子绝）。 鼠标移入，文字条从一行展开成两行 —— 奇数卡片直接铺满整张图。

三、这几行是关键

.list1, .list2 { display: flex; flex-wrap: wrap; gap: 10px; }

/* 定宽：一行 3 张，2 个 gap 共 20px，所以减 20px */
.list1 li { flex: 0 0 calc((100% - 20px) / 3); }

.list1 li { position: relative; overflow: hidden; }  /* 父相 + 裁切溢出 */
.list1 img { width: 100%; height: 180px; object-fit: cover;
             transition: transform .6s ease; }

.list2 li p { position: absolute; left: 0; bottom: 0; width: 100%;
              height: 44px; transition: height .4s ease; }   /* 子绝 */
.list2 li:hover p { height: 88px; }                        /* 一行 → 两行 */
为什么 flex: 0 0 calc((100% - 20px) / 3) 里要减 20px？ 一行三张卡片之间有两个 gap，每个 10px，共占 20px。 这 20px 不属于任何一张卡片，所以宽度要先把它们扣掉再三等分。
