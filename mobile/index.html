录屏怎么放进来 VIDEO

用另一台手机拍屏或直接用系统录屏，导出 mp4 后命名为 task3.mp4、task4.mp4， 放进 mobile/video/，两个任务页里的视频位会自动加载并可以播放，不用改代码。

  • 任务三拍：双指放大（看倍数）→ 松手拖动 → 双击回 1× → 横屏再竖回。
  • 任务四拍：仪表静止 9.8 → 摇一次出菜 → 马上再摇（被冷却挡住）→ 点"点我抽一次"。
  • 视频建议 15～30 秒，竖屏，画质 720p 以上；拍的时候手指别挡住右下角倍数 / 仪表。

踩过的坑 PITFALLS

  • touchmove 里 preventDefault 不生效：默认是 passive 监听，浏览器警告"Unable to preventDefault inside passive listener"。加 { passive: false } 解决。
  • 双指缩放图片乱跳：只改 scale 不改 translate，图片绕自身中心放大，手指下的点被推走。用两指中点反推位移才稳。
  • devicemotion 一条数据都没有：用 file:// 打开收不到传感器，必须 HTTPS（Netlify 发布后正常）。
  • 一次摇动抽了七八道菜：事件每秒几十次，全部越过阈值。加 1.5s 冷却后一次摇动只算一次。

AI 提示词记录 PROMPTS

  • 第 1 轮："帮我写一个手机左右滑动切换卡片的页面，四张卡片。" → 返回的是只监听 click 的版本，手机上滑不动。
  • 第 2 轮："用 touchstart / touchend，changedTouches[0] 算横向位移，阈值 40px；加 300ms 冷却防止一次手势跳两张；容器加 touch-action: pan-y；切换用 0.3s 过渡。" → 可用。
  • 第 3 轮（缩放）："双指缩放用两指距离比例，以两指中点为缩放基准，位移要跟着修正，否则会跳。" → 补齐了 translate 公式。
  • 第 4 轮（摇一摇）："accelerationIncludingGravity 合成加速度超过 18 触发，冷却 1.5s，并且没有传感器时要显示不支持 + 降级按钮。" → 加上了降级分支。
05

答辩速记

QUICK ANSWERS
Q1为什么 touchend 里要用 changedTouches[0]？
抬手那一刻，这根手指已经从 touches 里移除了，用 touches[0] 拿到的是"还留在屏幕上的另一根手指"，或者 undefined。 changedTouches 专门装"这一次事件里变化的手指"，抬手时就是刚抬起的那根。
Q2阈值设成 5px 会怎样？
手指按下的抖动就有 3～8px，5px 挡不住，几乎每次点击都被判成滑动，点按钮变成翻页。40px 是"大于抖动、小于一次自然滑动"的经验值。
Q3双指缩放怎么保证不跳？
scale 和 translate 必须一起算：手势开始时记下两指中点、当前倍数、当前位移，每帧按新倍数反推位移，让起点中点下的内容仍然落在现在中点下。
Q4加了 touch-action: none 之后发生了什么？
这块区域的手势完全交给 JS，浏览器不再做页面滚动或缩放，所以 touchmove 的坐标是连续的，preventDefault 也才有效。 代价是这块区域里用户没法滚页面，所以只加在真正需要接管手势的容器上，其它地方保留默认。
Q5手机上没有传感器数据时，代码怎么走？
先挂监听、开 1.5 秒计时。没数据就把状态标成"当前设备不支持"，显示提示条，"点我抽一次"变成主操作；iOS 未授权则走按钮申请权限，被拒绝同样退回降级。
