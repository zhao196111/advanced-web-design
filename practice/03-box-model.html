二、一个盒子的四层结构

鼠标移到卡片上，4px 的边框会变蓝 —— 那一圈就是 border；border 里面的 16px 是 padding；卡片外面的 20px 是 margin。

margin 外边距
border 边框 4px
padding 内边距 16px
content 内容区
box-sizing: border-box 的意思是：写 width: 300px 时， 这 300px 里已经把 padding 和 border 算进去了，内容区会自动让位。 用 content-box（默认值）的话，盒子实际宽度 = width + padding × 2 + border × 2，很容易算超。

四、这一页记住的三句话

  • 能继承的：color、font-*、line-height、text-align、letter-spacing。
  • 不能继承的：border、padding、margin、width、height、background。
  • 盒子算不准时：先打开开发者工具的盒模型面板，四层颜色看得一清二楚。
