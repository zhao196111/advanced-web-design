Q&A

为什么 Key 不能放前端？

前端源码按 F12 全可见，放进去等于公开，会被盗刷额度。后端持 Key 转发，前端只和自己的 /api/ 通信。

多轮对话为什么传完整历史？

模型不记事，每次请求独立。前端维护 messages 数组，把用户问题和模型回答都 push 进去整体发送。

换平台要改哪几个值？

只改 .env 三行：BaseURL、Model ID、API Key。注意 baseURL 末尾的 /v1 不能多也不能少。

没有 Key 会白屏吗？

不会。自动进入离线演示模式，请求体照常组装、控制台照常打印收发数据，页面给出明确提示。
